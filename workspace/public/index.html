规则实现方式
实物数量区间不重叠同一库位内有效仓单的 [startQty,endQty) 区间两两相交检测;登记 / 拆分 / 合并 / 复检 / 出库每个事务提交前强制执行。
三锁定 + 登记生效质押锁定仓单 version、估值批次 valuationBatchId、权利人 financerId;登记回执到达前状态恒为「已锁定·未登记」,禁止宣称担保生效。
复检只重估受影响单复检生成新检验批并版本 +1,仅重算该仓单项下质押的担保值;不足转 SUPPLEMENTING 并生成补充担保要求,原质押不删除。
放行前置出库存在有效质押时,出库必须携带当前质权人签发的放行令牌;未还款只允许按放行数量部分出库。
并发 / 晚到 / 重放 / 故障写操作 FIFO 串行 + 写时复制事务(拆分崩溃整体回滚);排他质押拦截第二家;旧版本登记拒绝;登记回执 / 放行请求幂等去重。
